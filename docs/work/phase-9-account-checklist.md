## How to read this checklist

| Column             | Meaning                                                                  |
| ------------------ | ------------------------------------------------------------------------ |
| **Workflow**       | Product workflow name (implementation slice)                             |
| **Route**          | Locale-free Account path (`apps/auth` re-exports `@modules/*`)           |
| **Status**         | `done` · `partial` · `placeholder` · `missing`                           |
| **Pass condition** | What “done” means for Phase 9 sign-off                                   |
| **Evidence**       | Existing test file and/or manual verification step                       |
| **Org notes**      | **Owner** · **Member** · **Manager** · **Cross-org** · **No active org** |

Statuses reflect **repo state on audit date**, not production deployment with live Autumn/Stripe.
