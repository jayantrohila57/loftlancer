---
title: Notifications
description: In-app notifications when NOTIFICATIONS_ENABLED is on.
---

The `@features/notifications` feature delivers in-app notifications for registry `notifyOn` events (for example invitation received/accepted).

## Studio API

Procedures under the notifications router check notification actions:

- `notification.list`
- `notification.mark_read`
- `notification.mark_unread`

## MCP

Notification actions are `scope: "user"` in the registry. `listMcpExposedActions()` excludes user-scoped actions, so **notification tools are not registered** on the MCP server today even though handlers exist in `@loftlancer/orpc/mcp`. Use the studio notifications API or UI.

Enable `NOTIFICATIONS_ENABLED` and `NEXT_PUBLIC_NOTIFICATIONS_ENABLED` together in production.
