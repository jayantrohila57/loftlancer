## Prerequisites

- Node.js 22.14+ (root `package.json` `engines`)
- pnpm 12.11.2 (Corepack; root `packageManager`)
- PostgreSQL (`DATABASE_URL`)
- GitHub OAuth credentials

## Run the studio locally

From the repository root:

```bash
corepack enable
corepack prepare pnpm@12.11.2 --activate
pnpm install
# configure env per app — see README.md and docs/database.md
pnpm dev:studio
```

Studio runs at `http://localhost:3001` (see `apps/studio/package.json`).

## Run docs and other apps

```bash
pnpm dev:docs   # http://localhost:3001 — Fumadocs routes under /docs
pnpm dev:auth   # http://localhost:3000 — OAuth callbacks at /api/auth/*
```

Production serves the same apps on one origin: `https://loftlancer.com` with paths `/auth`, `/studio`, and docs (including `/docs/*`) via root `vercel.json`.
